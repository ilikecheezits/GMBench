# Status — 2026-11-12

Implements the three goals in `benchmark_plan_2026-08-07.md`.

## 1. Rigor
- Replaced the holistic C/P/I judge (saturated: every GPT-5-family model scored 0.979) with **rubric-item judging**:
  per-task weighted items with negative penalty items, one judge call per sample, scored the HealthBench way.
- Replaced area-wide keyword lists with **task-specific deterministic checks**: exact numbers, push-back and refusal
  detection, language, and length, with critical-check caps.
- Task bank grew from 24 to 36 tasks. New area: finance & accounting. New stress tags: traps (7), over-refusal (2), exact (6).
  Added a Vietnamese task.
- Reports include bootstrap CIs, judge-vs-objective agreement, and subset scores.

## 2. Benchmark of benchmarks
- External components: MMLU slice (nonprofit-relevant subjects), TruthfulQA MC1, BBQ, XSTest. They are vendored,
  fixed-seed and licence-documented. Fixed weights: core 0.60, others 0.10 each.

## 3. Adaptive evaluation
- `main.py profile`: the intake agent extracts a profile, asks follow-ups, and generates self-contained custom tasks
  with rubrics. The profile sets area weights, filters languages, and adjusts composite weights by published rules.
- `--no-agent` questionnaire for zero-API use.

## Deploy readiness
- `pyproject.toml` (`npbench` command), Dockerfile, CI workflow, 27 offline tests (including an end-to-end mock run).
- Cost estimate and confirmation before every paid run. Interrupted runs resume without re-billing.

## Model availability note
`gpt-4.1-nano` is deprecated on the API. The cheapest working candidates are `gpt-4o-mini`, `gpt-5-nano` and
`gpt-5.4-nano`. The judge default is `gpt-4.1-mini`; switch it if that model is retired.

## Next steps (highest value first)
1. **Expert calibration**: have 2–3 nonprofit practitioners grade ~50 responses against the rubrics. Report
   judge–human agreement (Cohen's κ per item) and revise any items where they disagree. This is what makes the
   benchmark credible to researchers.
2. Grow the core bank to 100+ tasks, prioritising non-U.S. contexts and more languages. Publish a held-out private
   split to limit contamination.
3. Run a second judge from a different provider and report inter-judge agreement.
4. Public leaderboard page from `results.json`, plus a web form wrapping `profile` for non-technical users.
